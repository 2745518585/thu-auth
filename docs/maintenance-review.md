# 检查与优化记录（2026-10-03）

## 配置兼容与性能

- 保留现有 `secret.service_name` 和凭据键 `账户:password`、`账户:fingerprint`。
- 兼容旧示例的 `password.service_name`；两者同时存在时使用 `secret`。读取不会重写配置文件。
- 配置向导保留顶层和嵌套自定义字段，禁用强制认证时保留原有强制认证间隔。
- 取消配置、密码或指纹输入不会覆盖原值。配置通过同目录临时文件和原子替换保存，写入失败时保留原文件。
- 缓存有效配置和编译后的校验器；检测文件变化后重载。返回独立副本，避免调用者污染缓存。
- 检查正整数时间参数，避免无等待循环或无效超时；交互式 IPv4 校验不再因非法文本抛出异常。

## 运行与认证

- 服务启动或周期内异常持续重试，连续失败逐步增加等待时间，恢复后回到扫描间隔。
- 单设备异常不会跳过其他设备；在线设备不再重复 ping。
- 故障后清理连接池、Cookie 和 WebVPN 路由缓存；仅成功发现的路由会缓存。
- GET/HEAD 最多尝试三次，POST 不自动重放；所有服务请求有默认超时。
- 从同一次登录页面提取公钥、验证码和 CSRF。验证码无法识别时刷新页面，最多三次。
- HTML 解析不再依赖引号样式、属性顺序；明确处理过期会话和无效响应。
- 提交认证后用在线列表确认状态，避免误报成功；对异常认证跳转目的地进行检查。
- OCR 延迟初始化，帮助/版本命令不加载模型。

## 日志

- 日志目录不可写时继续输出控制台日志。
- 隐藏 URL 查询参数及已知密码、指纹、WebVPN 密钥字段，包括异常堆栈中的相关文本。
- 不再在无效响应异常中输出原始指纹或 WebVPN 用户信息。
- 保留日志轮转和文件异常堆栈，控制台继续显示简洁信息；历史日志不会改写。
